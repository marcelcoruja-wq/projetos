🧠 Lógica y Arquitectura del Sistema

El sistema opera bajo una jerarquía estricta que garantiza que nunca te pierdas en el flujo de trabajo. Todo sigue este orden en embudo:

  • 1. Proyecto: Es el contenedor macro (Ej: Tour Brasil 2026).
  • 2. Milestone (Meta de Entrega): Las fechas clave del proyecto. Ordenan la prioridad de lo que se debe entregar primero.
  • 3. Carpeta (Subproyecto): Pertenecen a un Milestone. Organizan el trabajo en áreas (Ej: Carpeta "Diseño" para el Milestone "Fase 1").
  • 4. Tareas: Pertenecen a una Carpeta. Al completar una tarea, el sistema avanza automáticamente el progreso de su Carpeta y de su Milestone.

📖 Tutorial Rápido: El Flujo Perfecto

Paso 1: Registra tu Proyecto y Milestones
Haz clic en + Nuevo Proyecto. Además del nombre y entregable, aprovecha para definir ahí mismo los Milestones (los plazos grandes) que dictarán el ritmo de trabajo.
Paso 2: Crea las Carpetas conectadas a un Milestone
Entra al proyecto y haz clic en 📂 Nueva Carpeta. El sistema te pedirá asociar esa nueva carpeta a un Milestone existente. Así, el trabajo queda encapsulado en ese plazo específico.
Paso 3: Carga las Tareas Directamente a las Carpetas
Haz clic en + Nueva Tarea. Selecciona tu Milestone en el primer menú, y el sistema filtrará inteligentemente las Carpetas asociadas. Selecciona la carpeta y guarda tu tarea.
Paso 4: Domina el Filtro de Tareas en Cascada
Cuando tengas cientos de tareas, usa los filtros superiores de la pantalla. Al elegir un Milestone en el primer filtro, el segundo filtro se adapta instantáneamente para mostrar solo las Carpetas relevantes para ese plazo.
Paso 5: Navegación desde el Dashboard
El Dashboard te muestra todo ordenado por fecha de entrega. Al ver una Carpeta dentro de un Milestone, simplemente dale clic: el sistema abrirá la tabla de tareas ya aplicando los filtros para mostrarte exactamente el contenido de esa carpeta.
